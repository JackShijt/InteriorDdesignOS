# Orchestrator Example

## 示例对话

**用户**: 帮我设计一套 90 平米的两室一厅

**Orchestrator**:
1. 调用 Parser Agent 解析需求...
2. Parser 返回: {room_types: ["客厅", "主卧", "次卧", "厨房", "卫生间"], area: 90}
3. 调用 Design Agent 生成方案...
4. 调用 Layout Agent 规划布局...
5. 并行调用: Electrical, Plumbing, Lighting, Ceiling, Floor Agents...
6. 调用 Validator Agent 综合校验...
7. 调用 Drawing Agent 生成图纸...
8. 调用 Export Agent 导出...
9. ✅ 完成！图纸已生成至 workspace/projects/Project_001/output/
