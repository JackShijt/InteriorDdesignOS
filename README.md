# InteriorDesignOS

室内设计自动化操作系统 - 基于 AI Agent 的室内设计图纸生成平台

## 概述

InteriorDesignOS 是一个多代理协作系统，通过 AI 驱动的代理网络自动生成专业的室内设计施工图纸，涵盖平面布局、电气、给排水、照明、吊顶等全专业图纸。

## 目录结构

```
InteriorDesignOS/
├── agents/          # AI 代理定义与配置
├── skills/          # 可复用技能模块
├── schemas/         # 数据格式定义
├── standards/       # 行业标准规范
├── templates/       # CAD 模板与图框
├── knowledge/       # 专业知识库
├── reference/       # 参考资料
├── mcp/             # 模型上下文协议连接器
├── workspace/       # 工作空间与项目
├── tests/           # 测试用例
├── examples/        # 示例项目
├── scripts/         # 工具脚本
├── logs/            # 运行日志
└── docs/            # 系统文档
```
