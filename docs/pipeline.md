# Pipeline

## 处理流水线

```
输入 → 解析 → 设计 → 布局 → [专业深化] → 校验 → 修复 → 图纸 → 导出
                                     ├─ 电气
                                     ├─ 给排水
                                     ├─ 照明
                                     ├─ 吊顶
                                     ├─ 地面
                                     └─ 立面
```

## 并行处理
专业深化阶段的所有代理可并行执行，大幅提升效率。
